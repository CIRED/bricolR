# BricolR rasters

In this presentation we try to make a small presentation of how rasters can be manipulated with R. The slideshow is a support but the R markdown file serves as a experimental playground.

The presentation isstructured in 4 main parts:
### Rasters files with R: the basics
  In this part, we  import population datasets for France and Spain and explore these rasters a little bit.

### Raster manipulation
We manipulate the rasters in order to compute the sum of men and women, have a map with Spain and France, crop the data to one region.

### Raster and shapefiles with R

We see how you can manipulate both rasters and vectors data, transform one into the other. We will mask a raster within a region, extract the values depending the regions, transform a raster into vector data...

### Can GDAL help me go faster?

Examples of how much faster GDAL can be for resampling or for merging large datasets
