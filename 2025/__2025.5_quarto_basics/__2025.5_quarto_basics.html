1 Introduction

Quarto est une extension de rmarkdown qui supporte quatre langages de programmation R, python, JS et Julia. Il peut être utilisé dans chacun des ide supportant ces langages et bien sûr dans VScode.

Quarto utilise toute la syntaxe de rmarkdown en mode plus étendu encore puisqu’il supporte bien plus de formats de documents en production.

Il est conseillé d’installer pandoc bien que la version partielle installée avec quarto ou rmarkdown soit suffisante pour les travaux de base.

2.1 Syntaxe de base de rmarkdown / quarto

On utilise l’éditeur rmarkdown qui est le même que celui de quarto.

montrer ici mode source / visuel

On peut donc utiliser la syntaxe de base de rmarkdown pour écrire du texte et le mettre en forme.

Les mises en formes sont immédiates et on peut écrire toute sorte de texte au kilomètre. Les mises en formes sont immédiatement appliquées.

On a donc des mises en formes directes : (a2) (b3) voire du code verbatim x <- 1.

Tout cela permet de composer des tutoriels, sites, présentations etc.

Avec pandoc on accède à tex dans tous les environnements de développement.

2.2 Traitements dans quarto

Les traitements quelque soit la plateforme s’affichent dans des blocs de markdown executables.

Ils peuvent être soit insérés, mis en formes voire même standardisés sous forme de cadres formatés.

Les blocs de code rmarkdown knitr doivent respecter les règles importantes suivantes :

  1. ils doivent tenir en une seule ligne ;
  2. ils doivent tous être différents sinon knitr stopera l’exécution ;
  3. préférez les tirers comme séparateurs de titres de blocs
